비교 방식

누적: 관찰 기록을 전부 그대로 질문에 넣습니다.
압축: 기록 5개를 기존 compress_memory()로 요약하고 장기 기억에 이어 붙입니다.

30개 관찰 · 요약 6회 · 4개 시점에서 조건별 3회 반복. 기존 질문 프롬프트와 최근 프레임 3개는 양쪽에 동일하게 사용했습니다.

공개 2B 모델의 로컬 추론 비교입니다. 원본 8B 모델, 위험 탐지 정확도, 네트워크·대기열 지연은 이번 결과에 포함하지 않습니다.

입력량과 답변 시간

각 값은 3회 중앙값입니다. 토큰에는 프롬프트와 최근 이미지 입력도 포함됩니다. 첫 토큰 시간은 모델 생성 시작부터 측정합니다.

요약 비용까지 포함하면

영상 관찰은 두 방식이 공유합니다. 비교 총비용은 공통 관찰 비용 + 각 측정 시점에 질문 1회(반복 중앙값) + 해당 방식의 요약 비용으로 계산합니다. 고정 출력 통제 실험과 반복 측정 비용은 이 비교 총비용에서 제외합니다.
